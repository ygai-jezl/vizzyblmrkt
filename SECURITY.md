# Security policy

## Report a vulnerability privately

Please don't report security problems in a public issue, pull request or
discussion. Use GitHub's private vulnerability reporting instead:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Fill in the form. Only you and the maintainers can see it.

## What to include

- What the problem is, and what someone could do with it.
- Where it is: the file, route or screen, and the commit you tested.
- Steps to reproduce it, or a small proof of concept.
- Any logs, requests or screenshots that help. Remove secrets and real people's
  data first.
- Whether you think anyone is already exploiting it.

## What happens next

We aim to reply within a few working days. We'll confirm the problem, keep you
posted while we fix it, and credit you in the advisory if you'd like. Please
give us a fair chance to ship a fix before you share details publicly.

## Scope

This policy covers the code in this repository. If you run your own copy, your
deployment's settings, secrets and access are yours to look after.
